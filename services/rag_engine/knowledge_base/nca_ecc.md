# NCA Essential Cybersecurity Controls (ECC-1:2018) for AI Infrastructure
**Source Identifier**: `NCA_ECC_2018`  
**Publishing Body**: National Cybersecurity Authority (NCA)  
**Version**: ECC-1:2018  
**Category**: Core AI Governance  

---

## Domain 1: Cybersecurity Governance

### Control 1-1: Cybersecurity Strategy for AI Assets
Organizations must incorporate AI hardware, model weights, and data pipelines into the corporate cybersecurity strategy and risk management framework.

---

## Domain 2: Cybersecurity Defense

### Control 2-1: Network Security & AI Endpoint Isolation
API endpoints serving AI inferences and vector database instances must be isolated within secure network segments with strict firewalls and intrusion prevention systems.

### Control 2-3: Cryptographic Protection of AI Models
AI model binaries, parameters, and vector embeddings must be protected using strong encryption standards (AES-256 at rest, TLS 1.3 in transit).

### Control 2-7: Vulnerability Management & Model Poisoning
Regular vulnerability assessments and penetration testing must be performed on AI API services to prevent adversarial prompt injection, model poisoning, and data extraction attacks.
